## What we do not build (anti-scope)

These are *intentionally* not on the roadmap. Stated to remove ambiguity:

- A token sale or presale for $FORGE — shares mint to contributors only.
- An exchange / DEX / launchpad — out of scope; Foundry is a protocol, not a venue.
- A GPU marketplace — Foundry consumes 0G Compute; it does not compete with hardware providers.
- A general-purpose chat assistant — Foundry exposes Ingots into other agent surfaces via adapters.
- Cross-chain bridges this year — 0G-native; bridges are a Month-6+ consideration.
