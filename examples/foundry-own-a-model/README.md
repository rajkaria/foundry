# foundry-own-a-model

Upload data → create a Forge → contribute → own a share of the Ingot.

> **Foundry (ownership) recipe.** This opts you into the Foundry ownership
> layer — it is not the default. For the neutral path see
> [`../storage-roundtrip`](../storage-roundtrip) and
> [`../inference-quickstart`](../inference-quickstart).

```bash
npm install
cp .env.example .env   # paste a funded Galileo key
npm start
```

The contribution transaction is your on-chain claim to a share of the Ingot
the Forge produces.
