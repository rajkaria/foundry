# Changelog

The curated, human-readable history of the **0gkit** toolkit. Per-package
machine changelogs are generated by [changesets](./.changeset/README.md) into
each package's own `CHANGELOG.md` on release; this file is the narrative.

Versions follow [semver](https://semver.org). The `@0gkit/*` packages are
version-linked and release together.

## Unreleased

The first public release of the toolkit, assembled in dependency-ordered
sub-projects. Pending changeset: **0gkit initial public release** (minor).

### Added

- **`@0gkit/core` + `@0gkit/chain`** — network presets (Aristotle, Galileo,
  local), viem client factory, `Receipt`, the `ZeroGError` taxonomy, faucet
  and `waitForReceipt`, explorer URLs. CI neutrality boundary rule live.
- **Primitives** — `@0gkit/storage`, `@0gkit/compute`, `@0gkit/da`,
  `@0gkit/attestation`. Each independently installable with a `.raw` escape
  hatch to the underlying 0G SDK; ≥80% coverage; opt-in live Galileo tests.
- **`@0gkit/cli`** — the language-agnostic `0g` CLI including `0g init` and
  `0g doctor`; pretty human output by default, `--json` for scripting.
- **`@0gkit/mcp`** — every primitive as an `og_*` MCP tool; the Foundry tools
  are an opt-in plugin, absent by default.
- **`@foundryprotocol/sdk`** — re-implemented on `@0gkit/*` internals; public
  API unchanged; the duplicated storage/da/attestation/inference code deleted.
- **`create-foundry-app`** + **`examples/`** — A–E archetype templates, a
  one-command live-Ingot demo, and degit-able recipes.
- **`@0gkit/react`** — `useUpload`, `useDownload`, `useInference`,
  `useAttestation` hooks over the neutral primitives.
- **`apps/playground`** — zero-setup web console: run an action, see the
  receipt + explorer link, and copy working code in CLI / TypeScript / curl /
  MCP form. Pure client over the public packages.
- **Community + release** — `CONTRIBUTING`, `CODE_OF_CONDUCT`, `SECURITY`,
  issue/PR/discussion templates, a curated good-first-issue backlog, and
  changesets-driven coordinated versioning + npm publishing.
